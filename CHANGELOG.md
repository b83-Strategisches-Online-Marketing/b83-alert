# Changelog

## 1.1.0 – 2026-11-01

### Neu
- Eigenes Icon und Banner im b83-Stil: erscheinen in der Update-Liste und unter „Details ansehen“
- „Details ansehen“ zeigt jetzt eine Beschreibung des Plugins

## 1.0.0 – 2026-10-30

- Erste Version
- Pop-up mit formatiertem Text (Überschriften, Fett, Listen, Links, Bilder), drei Arten: Information, Warnung, Alarm
- Laufschrift (Ticker) mit einer Zeile Text und optionalem Link
- Zeitsteuerung „anzeigen ab / bis“, auch auf gecachten Seiten pünktlich
- Eingabe für Kunden im Dashboard-Widget „Mitteilung“ und unter b83 → Alert (ab Redakteur)
- Alert-Einstellungen für Administratoren: Startseite, alle Seiten, ausgewählte Seiten oder Shortcode; Häufigkeit, Verzögerung; Design mit Live-Vorschau (Hintergrund, Textfarbe, Schatten, Ecken, Breite, Abdunklung); Laufschrift-Position, Tempo, Schriftgröße, Farben
- Shortcodes `[b83_alert_popup]`, `[b83_alert_ticker]`, `[b83_alert_box]`
- Vorschau-Link für Redakteure, Cache-Leerung, Updates über GitHub
